# 카드뉴스 각색기 (쿠팡파트너스용)

인스타그램 카드뉴스(캐러셀) 게시물 주소를 넣고 버튼 하나를 누르면,
슬라이드 글·캡션을 **원본과 다르게 각색**하고 깔끔한 디자인을 입혀 PNG로 내려받는 웹앱입니다.
50~60대도 혼자 쓸 수 있도록 큰 글씨·큰 버튼·한 화면 한 단계로 만들었습니다.

## 사용 흐름

1. **주소 넣기** → `카드뉴스 새로 만들기` 버튼
2. 자동으로 게시물 사진·캡션을 가져오고, AI가 사진 속 글씨를 읽어 각색
   - 자동 추출이 실패하면 **사진 직접 올리기 + 원문 붙여넣기** 화면으로 자동 안내
3. **미리보기**에서 **디자인 템플릿** 고르기, 카드마다 사진 바꾸기 또는 **✨ AI 새 사진**, 글 직접 수정(1번=표지 제목, 2번부터=본문), 워터마크 문구·캡션 수정
4. **승인하고 내려받기** → `slide_01.png …` (1080×1350) + `caption.txt` 를 zip으로 저장
   (휴대폰은 완성 사진을 눌러 한 장씩 저장 가능)

캡션 끝에는 쿠팡 파트너스 고지 문구가 자동으로 붙습니다.

## 슬라이드 디자인

저장소 루트의 레퍼런스 4장(`ref-slide1-cover.jpg` ~ `ref-slide4-cta.jpg`)을 픽셀 측정해 그대로 옮겼습니다 (`components/SlideCard.tsx`).

- 공통: 1080×1350, 배경에 그 장의 사진을 꽉 차게, 오른쪽 위 `[광고]`(쿠팡 파트너스 고지), 아래 가운데 워터마크(기본 `맛집도둑`, 템플릿에 저장되고 편집 화면에서도 수정 가능)
- 1번 장(표지): 큰 흰 제목, 검은 외곽선·그림자, 박스 없음, 아래쪽 왼쪽 정렬
- 2번 장부터: 아래 가운데 반투명 박스(레퍼런스 측정값: 흰색 48% + 얇은 검은 테두리) 안에 흰 글씨 가운데 정렬
- 글꼴: 제목·본문 [Jua](https://fonts.google.com/specimen/Jua)(둥근 굵은 고딕, SIL OFL), `[광고]`·워터마크 Pretendard
- 글이 길면 글자 크기를 자동으로 줄입니다

## 디자인 템플릿

위 디자인은 **기본 제공 템플릿 "기본 디자인"**이고, 글꼴·색·글상자·워터마크를 바꾼 **내 템플릿**을 만들어 저장할 수 있습니다
(`/templates` 탭, 또는 편집 화면의 `🎨 템플릿 만들기 · 고치기`).

- **표지(1번 장)와 내지(2번 장부터)를 따로** 설정: 글꼴, 글자 크기(작게/보통/크게), 글자색, 글자 테두리, 글 위치(위·가운데·아래), 글 정렬, 글상자(사용 여부·색·진하기·테두리)
- **워터마크**: 문구·글꼴·색·진하기·위치(아래 가운데 / 아래 왼쪽 / 위 왼쪽). 문구는 템플릿에 함께 저장돼 다음에도 그대로 나옵니다
- 오른쪽 위 `[광고]`는 쿠팡 파트너스 고지라 **끌 수 없습니다**
- 기본 제공 3종(`기본 디자인`, `굵은 자막형`, `깔끔한 흰 박스`)은 고칠 수 없고 **복제**해서 쓰며, 내가 만든 템플릿은 몇 개든 저장·수정·삭제할 수 있습니다
- 저장 위치는 **이 브라우저**(localStorage: `cardnews.templates.v1`, 고른 템플릿은 `cardnews.template.active`) — 서버에 올라가지 않습니다
- 편집 화면에서 템플릿을 고치면 **겹쳐서** 열립니다. 만들던 카드뉴스가 사라지지 않게 하려는 것입니다

### 글꼴

내장 2종(주아·프리텐다드) + jsDelivr CDN([fonts-archive](https://github.com/fonts-archive))에서 내려받는 12종.
고른 글꼴만 그때 내려받고(`lib/webfonts.ts`의 `ensureFont`), PNG로 저장할 때 글꼴을 그림 안에 심습니다(CORS 허용 CDN이라 가능).

| 용도 | 글꼴 |
|---|---|
| 둥근 고딕 | 주아(내장·기본), 비둘기마요 |
| 굵은 제목 | 도현, 지마켓 산스, KCC 간판체, 강원교육 파워, 강원교육 모두 |
| 가는 고딕·명조 | 카페24 오스퀘어 에어, 마루부리, 프리텐다드(내장) |
| 손글씨 | HS봄바람 3.0, 강원교육 현옥샘, 강원교육 새움 |
| 영문 | Helvetica Neue(기기 글꼴) |

> 요청받은 목록 중 **KoreanCNML·BBTreeG_B·HYHeadLine-Medium**은 무료 웹폰트 CDN에 없어 넣지 못했습니다(상용 라이선스로 보입니다).
> 쓰려면 웹폰트 파일을 직접 구해 `app/fonts/`에 넣고 `lib/webfonts.ts`에 추가하면 됩니다.

## AI (OpenAI)

| 용도 | 모델 (기본값) | 호출 위치 |
|---|---|---|
| 사진 속 글씨 읽기(vision) + 각색 | `gpt-5-mini` — Responses API, 구조화 출력(JSON 스키마) | `lib/remix.ts` |
| AI 새 사진 ① 원본 사진 분석 | `gpt-5-mini` — 비전, 구조화 출력 | `lib/image-gen.ts` |
| AI 새 사진 ② 같은 요리를 새로 생성 | `gpt-image-2.5-sunburst` — Images API generations (분석 실패 시 edits) | `lib/image-gen.ts` |

> ⚠️ OpenAI 공지 기준 **`gpt-5-mini`는 2026-12-11 지원 종료 예정**입니다. 그 전에 `OPENAI_TEXT_MODEL`만 바꾸면
> 코드 수정 없이 교체됩니다 (OpenAI 권장 후속: `gpt-5.6-terra`). 사진 모델도 `OPENAI_IMAGE_MODEL`로 교체 가능합니다.

### AI 새 사진

- 각 장의 `✨ AI 새 사진` 버튼을 누를 때만 그 장 1장을 만듭니다 (전체 자동 생성 없음 — 비용 보호, 실패해도 자동 재시도 안 함).
- **분석 후 새로 생성(기본)**: 그 장의 지금 사진을 `gpt-5-mini`가 분석(요리 이름·재료·조리도구, 원본의 앵글·배치·배경)하고,
  그 설명으로 **같은 요리·재료를 완전히 새로 촬영한 사진**을 만듭니다. 원본 사진을 이미지 모델에 넣지 않아 원본 구도에 끌려가지 않고,
  원본에 박힌 글자·반투명 텍스트박스·하단 그라데이션·워터마크가 옮겨 올 길이 없습니다.
  - 구도·배경을 확실히 다르게: 카메라 앵글은 원본 앵글을 뺀 후보(위에서·45도·눈높이·클로즈업) 중에서, 배경은 6가지 후보 중에서 무작위로 고르고,
    배치는 분석이 제안한 다른 플레이팅으로 바꿉니다. 프롬프트에 원본의 앵글·배치·배경을 적고 "따라 하지 말 것"을 명시합니다. 누를 때마다 다른 사진이 나옵니다.
  - 더 맛있어 보이게: 전문 푸드 포토그래피, 먹음직스러운 조명, 선명한 질감, 윤기, 생생한 색감, 뜨거운 요리는 모락모락 김.
  - 글자·그래픽 제거: 텍스트·자막·워터마크·`[광고]`·하단 그라데이션·반투명 텍스트박스·테두리 모두 금지 (영문 + 한글로 명시).
- 분석이 실패하면 자동으로 **편집 방식**(원본 사진을 넣어 과감하게 바꾸라고 지시)으로 만듭니다. `OPENAI_IMAGE_MODE=edit`로 항상 편집 방식을 쓸 수도 있습니다(원본을 더 닮음).
- 사진이 없는 장은 글 내용으로 새로 만듭니다.
- 출력: `gpt-image-2.5-*`는 정확히 4:5인 1088×1360으로 받고(그 외 모델은 1024×1536), 브라우저에서 1080×1350으로 꽉 차게 잘라 배경을 교체합니다.
- 만드는 중엔 미리보기 위에 로딩 표시, 실패하면 한글 안내, `↩ 이전 사진으로` 되돌리기 가능.
- 모델 선택: `gpt-image-1`은 이미 서비스 종료, `gpt-image-1-mini`는 2026-12-01 종료 예정이라, 편집 정밀도가 가장 높다고 안내된 `gpt-image-2.5-sunburst`를 기본값으로 했습니다.

### 비용 (월 $3, 하루 1건·4장 기준)

저비용 설정: 각색은 `reasoning.effort: low`, 출력 상한 8,000토큰, 재시도 1회. AI 사진은 `low` 품질, 버튼을 누를 때만 1장씩, 재시도 없음.

| 항목 | 1건(4장) 대략 | 한 달(30건) 대략 |
|---|---|---|
| 각색 (gpt-5-mini, 입력 $0.25 / 출력 $2 per 1M) | 약 $0.005~0.02 | 약 $0.15~0.6 |
| AI 새 사진 (gpt-image-2.5-sunburst, low) | 장당 가격 미공개 | 아래 참고 |

AI 새 사진은 OpenAI가 장당 가격을 공개하지 않고 토큰 단가(사진 입력 $8 / 사진 출력 $30 per 1M)만 공개합니다.
처음 몇 장을 만든 뒤 대시보드 Usage에서 실제 장당 비용을 확인하세요. 월 $3 안에 맞추기 빠듯하면
`OPENAI_IMAGE_MODEL=gpt-image-1-mini`(토큰 단가 약 1/4, low 출력 장당 약 $0.006 + 입력, 단 2026-12-01 종료 예정)로 바꿀 수 있습니다.
각색 쪽 사진 입력 토큰 수도 해상도에 따라 달라지므로 위 수치는 추정치입니다. **실제 한도는 OpenAI 대시보드에서 거세요**:
platform.openai.com → Settings → Limits(프로젝트 Budget)에서 월 $3로 설정. 한도를 다 쓰면 앱은
"이번 달 사용 한도를 다 쓴 거예요" 안내를 보여주고, 수동 편집·다운로드는 그대로 쓸 수 있습니다.

## 구조

| 경로 | 역할 |
|---|---|
| `app/page.tsx` | 화면 흐름 (주소 입력 → 수동 업로드 → 로딩 → 편집) |
| `app/templates/page.tsx` | 디자인 템플릿 탭 |
| `components/Editor.tsx` | 템플릿 고르기·미리보기·수정·AI 사진·승인/다운로드 |
| `components/TemplateManager.tsx` | 템플릿 목록·만들기·고치기 (탭과 겹침 화면에서 함께 씀) |
| `components/SlideCard.tsx` | 슬라이드 그리기 (1080×1350, 템플릿 설정을 적용) |
| `lib/templates.ts` | 템플릿 자료형·기본 제공 3종·브라우저 저장 |
| `lib/webfonts.ts` | 고를 수 있는 글꼴 14종, 쓰는 글꼴만 CDN에서 내려받기 |
| `app/api/extract` | 인스타 게시물 → 이미지 URL + 캡션 (GraphQL → 임베드 페이지 → og 태그 순으로 시도) |
| `app/api/image` | 인스타 CDN 이미지 프록시 (CORS 회피, 인스타 CDN 호스트만 허용) |
| `app/api/remix` | gpt-5-mini가 슬라이드 사진 속 글을 읽고 어미·톤·문장구조를 바꿔 각색 |
| `app/api/image-gen` | AI 새 사진: 원본 사진 → 같은 음식·다른 구도·글자 없는 새 사진 |
| `lib/openai.ts` | OpenAI 클라이언트, 모델 ID, 오류 메시지 |
| `lib/export.ts` | 브라우저에서 PNG 렌더링(html-to-image) + zip(JSZip) |

## 로컬 실행

```bash
npm install
cp .env.local.example .env.local   # OPENAI_API_KEY 입력
npm run dev
```

키 없이 화면만 보려면 `.env.local`에 `MOCK_LLM=1`을 넣고 실행하세요 (예시 문장·예시 사진).

## 테스트

```bash
npm run build
npm run test:ai    # 가짜 OpenAI 서버로 각색·AI 새 사진의 요청 형식(원본 사진·크기·글자 제거 지시)과 오류 처리 확인
npm run test:e2e      # 데모 모드로 화면 전체 흐름(업로드→각색→수정→zip 다운로드) 확인, Playwright 필요
npm run test:template # 템플릿 만들기→저장→편집 화면 적용→PNG 저장→삭제 확인 (CDN 글꼴을 받아오므로 인터넷 필요)
```

Playwright는 저장소 의존성에 넣지 않았습니다. 테스트 전에 `npm i -D playwright --no-save && npx playwright install chromium`을 한 번 실행하세요.

## Vercel 배포

1. 이 저장소를 Vercel에 Import
2. Settings → Environment Variables 에 `OPENAI_API_KEY` 추가
3. Deploy

| 환경변수 | 필수 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | ✅ | OpenAI API 키 |
| `OPENAI_TEXT_MODEL` | | 기본 `gpt-5-mini` |
| `OPENAI_IMAGE_MODEL` | | 기본 `gpt-image-2.5-sunburst` (이미지 입력=편집 지원 모델이어야 함) |
| `OPENAI_IMAGE_QUALITY` | | `low`(기본) / `medium` / `high`. 더 고급스러운 사진을 원하면 `medium` (비용 증가) |
| `OPENAI_IMAGE_MODE` | | `describe`(기본, 분석 후 새로 생성) / `edit`(원본 사진 편집, 원본을 더 닮음) |
| `NEXT_PUBLIC_ENABLE_IMAGE_GEN` | | 기본 켜짐. `0`이면 'AI 새 사진' 버튼 숨김. 바꾸면 **재배포** 필요 |
| `IG_DOC_ID` | | 인스타 GraphQL doc_id. 인스타 변경으로 자동 추출이 깨지면 교체 |
| `MOCK_LLM` | | `1`이면 데모 모드. **실서비스에선 비워 두기** |

`/api/remix`는 30초~1분 걸릴 수 있어 `maxDuration = 120`, `/api/image-gen`은 분석+생성으로 1~2분 걸릴 수 있어 `maxDuration = 240`으로 두었습니다
(요금제별 함수 최대 실행 시간을 확인하세요).

## 알려진 한계

- 인스타그램 자동 추출은 인스타 측 차단·구조 변경에 따라 실패할 수 있습니다 (특히 Vercel 서버 IP). 이때는 수동 경로를 쓰면 됩니다.
- AI 새 사진은 글씨 없는 배경 사진만 만듭니다. 글씨는 앱의 디자인 템플릿이 위에 얹습니다. AI가 드물게 글자 흔적을 남길 수 있으니 결과를 보고 마음에 안 들면 다시 누르거나 되돌리세요.
